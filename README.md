# Pomotime



Pomotime

Aplicativo web Pomotime para foco e tarefas. 
Inclui timer personalizável com modos Pomodoro, pausas, 
alarmes sonoros, sons ambiente relaxantes gerados por código 
e gerenciamento completo de listas de tarefas diárias. 
Com interface moderna em modo escuro, a ferramenta utiliza 
a Web Audio API para sintetizar múltiplos alarmes e ruídos 
ambiente relaxantes de forma nativa, dispensando arquivos externos. 
Inclui um painel dinâmico para adicionar, concluir e excluir tarefas 
diárias. 

English
Pomotime web application for focus and tasks. It includes a customizable timer 
with Pomodoro modes, breaks, sound alarms, relaxing ambient 
sounds generated by code, and full daily task list management. 
Featuring a modern dark mode interface, the tool uses the Web Audio API to natively 
synthesize multiple alarms and relaxing ambient noises without external files. 
It includes a dynamic panel to add, complete, and delete daily tasks.

Español
Aplicación web Pomotime para enfoque y tareas. 
Incluye un temporizador personalizable con modos Pomodoro, 
pausas, alarmas sonoras, sonidos ambientales relajantes 
generados por código y gestión completa de listas de tareas diarias. 
Con una interfaz moderna en modo oscuro, la herramienta utiliza la Web 
Audio API para sintetizar de forma nativa múltiples alarmas y ruidos ambientales 
relajantes, prescindiendo de archivos externos. Incluye un panel 
dinámico para agregar, completar y eliminar tareas diarias.
